# Cybersecurity Awareness Bot

## About the Project

The Cybersecurity Awareness Bot is a C# console application designed to provide basic cybersecurity awareness information.

## Features

- Voice greeting
- ASCII cybersecurity artwork
- Personalised user greeting
- Basic cybersecurity questions and responses
- Password safety information
- Phishing information
- Safe browsing advice
- Suspicious link advice
- Malware information
- Input validation
- Coloured console interface
- Structured C# code

## How to Run

1. Open the project in Visual Studio.
2. Build the solution.
3. Make sure the voice_greeting.wav file is included in the Assets folder.
4. Run the application.
5. Enter your name.
6. Ask the chatbot a cybersecurity-related question.
7. Type `exit` to close the application.
